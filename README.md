FORGE — version installable sur iPhone
Contenu :
- index.html : application FORGE
- manifest.webmanifest : informations d'installation
- sw.js : cache hors ligne de l'application
- icons/ : icônes iPhone

Mise en ligne gratuite :
1. Décompressez ce dossier.
2. Publiez tous les fichiers et le dossier icons sur un hébergement HTTPS (par exemple GitHub Pages).
3. Sur iPhone, ouvrez l'adresse du site dans Safari.
4. Touchez Partager > Sur l'écran d'accueil > Ajouter.

Les données restent enregistrées dans le stockage local du navigateur. Cette version ne synchronise pas encore les données entre appareils.
